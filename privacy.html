Privacy policy

Effective date: 15 October 2026

This policy describes the privacy practices of Ad Scriptorium Publisher, a private local publishing tool operated by the owner of the Ad Scriptorium YouTube channels. The tool is not offered to the public and has no other end users.

Information processed

  • Google authorization tokens. When the owner authorizes the tool, Google returns OAuth tokens. The tool stores these tokens locally on the owner’s computer so it can make authorized requests. It never asks for or stores the owner’s Google password.
  • YouTube account and content data. The tool accesses the owner’s channel and video data needed for publishing, such as channel/video identifiers, titles, descriptions, localization data, thumbnails, caption tracks, and publishing status. It may also read or update playlist metadata when the owner uses the playlist feature.
  • Local project files. Video metadata, subtitle source files, and publishing status are held in the owner’s local project files and local application state. Video and audio source files are not sent through the YouTube Data API except when the owner explicitly uploads a video; audio dubbing tracks are uploaded separately in YouTube Studio.

How information is used and shared

The owner uses this information to manage their own channels. The tool sends data to Google/YouTube only when the owner authorizes and initiates an API operation, such as uploading a video or writing metadata, a thumbnail, a caption track, or playlist metadata. Google processes that information under the Google Privacy Policy and YouTube’s terms.

The tool does not sell personal information, show advertising, or provide other creators access to the owner’s authorized data. The publishing backend does not send YouTube API data to analytics providers or AI services. Other optional dubbing workflows may send user-selected text or audio to their configured providers; that is separate from this YouTube publishing integration.

Storage and security

The backend runs on the owner’s computer and does not operate a public server. OAuth credentials and working data remain in local application storage controlled by the owner. Access to that computer and its files is controlled by the owner; no claim is made that local files are encrypted by this tool.

The public documentation pages are hosted by GitHub Pages. GitHub may process technical request data when serving these pages, as described in the GitHub Privacy Statement.

Retention and deletion

The owner can remove the local OAuth token and project data at any time. To stop API access, the owner can delete the local authorization file and revoke the tool’s access in their Google Account settings. Data already published to YouTube remains under the owner’s YouTube account and can be managed there. When the operator receives a request to delete personal data held locally, it will be deleted within 30 days.

Children

This private tool is not directed to children and is not offered to the public.

Contact

For privacy questions or deletion requests, contact mail@skyward.pro.
